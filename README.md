# Vortex Cyber Defense

> **Autonomous Industrial & Sovereign Threat Mitigation Platform**

An interactive cybersecurity and industrial intelligence landing platform built with **React**, **Tailwind CSS**, and **Vite**, featuring high-performance physics-based micro-interactions, gaze tracking, and 3D card deck mechanics.

---

## Key Features

- **3D Radial Rosette Card Deck**:
  - Interactive multi-card rosette deck representing 10 engineering fundamentals.
  - Natural drag-and-toss gesture support with drop velocity, momentum tracking, and continuous throw-to-bottom card rotation.
  - Modal technical detail view with full portal isolation.
- **Interactive Gaze Tracking Hero**:
  - Real-time cursor gaze tracking with smooth interpolation.
  - Video stream switching and responsive gaze vector calculations.
- **Brand Typography & Wordmark**:
  - Interactive brand header with animated hover illumination.
- **Modern Glassmorphism UI**:
  - Dark sovereign aesthetic with deep navy gradients, glowing badges, and responsive typography.

---

## Tech Stack

- **Framework**: React 19
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React

## Getting Started

### Prerequisites
- Node.js (v18+ recommended)
- npm or yarn

### Installation

```bash
git clone https://github.com/Shrey819/Cyber.git
cd Cyber
npm install
```

### Running Locally

```bash
npm run dev
```

Visit `http://localhost:5173/` in your browser.

### Building for Production

```bash
npm run build
```
